# 🍽️ FitVIT — Smart Mess Management for VIT

> An intelligent mess management platform for VIT University — optimizing food quality, reducing waste, and enhancing the student dining experience.

## 📂 Repository Structure

This repository uses a **branch-based organization**:

| Branch | Contents | Status |
|--------|----------|--------|
| `main` | Project overview & documentation | ✅ Active |
| `app` | Mobile app (Expo/React Native) — **v3** & **v4** | ✅ Active |
| `website` | Web portal | 🔜 Coming soon |

## 📱 Mobile App (`app` branch)

### FitVITv3
- Student portal with meal ratings, preferences & feedback
- Admin dashboard with predictive analytics
- Supabase backend integration

### FitVITv4
- Enhanced waste management analytics
- Improved admin dashboard with ML-driven predictions
- Advanced student experience features

## 🌐 Website (`website` branch)

_Coming soon — reserved for the web portal._

## 🛠️ Tech Stack

- **Frontend:** React Native (Expo Router)
- **Backend:** Supabase (PostgreSQL + Auth + Edge Functions)
- **Analytics:** Custom predictive engine with ML models
- **Design:** Living Greenhouse design system
