Stitch Style Guide (from DESIGN.md)

This page captures the intended essence of your uploaded Stitch system so implementation decisions remain faithful.

Core Intent

The product tone is high-performance nutrition for students, framed as an editorial, greenhouse-inspired digital experience rather than a generic utility app.

Visual Direction

Primary green palette, warm-white background, layered tonal surfaces, strong rounded geometry, and minimal hard borders (background separation over divider lines).

Typography

Display/headline voice: Plus Jakarta Sans. Body/labels: Manrope. Big hierarchy jumps are intentional for editorial rhythm.

Component Rules

Pill CTAs with gradient fills, rounded input fields, chip-based filters, anti-divider list spacing, and soft tonal cards over flat border-heavy layouts.

What This Rebuild Does

Each of the 10 Stitch HTML exports is rendered directly in-page, and each page has a clear description of intended purpose so the full 11-page site reflects your original design language.
